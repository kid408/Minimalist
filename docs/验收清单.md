## 8. 排错速查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 编译报缩进错误 | `.gd` 用了空格缩进 | 全部改为 Tab |
| 技能全失效 / 数值为 0 | TSV 列数错位或空字段填了占位符 | 空字段 = 两个连续 Tab；列数 = 表头 |
| 属性 tooltip 与实际不符 | 自己又算了一遍公式 | 调 `Formula` |
| 光环不生效 | 换槽/拾取后没触发重算 | `AuraSystem` 脏标记重算 |
| 预览遮罩在冷却时仍显示 | 漏了"CD 中/能量不足只飘字" | 见规格书 §12.4 |
| 角色/图标视觉大小偏小 | `ProcArt` 生成尺寸不符合契约 | 见规格书 §11.2 |
| HUD 位置错乱 | 用了 anchors 而非固定 offset | 见规格书 §12.1 |
| 商人/祭坛用不了 | 交互没过滤"只有玩家" | 判定 `body is Player` |
| 死亡后没有无敌 | 无敌期没在伤害入口拦截 | 见规格书 §6.3 步骤 4 |
| 威胁等级只影响新怪 | 忘了对在场敌人做增量缩放 | 见规格书 §8.3 |
